# ScrollGuard AI — Repository Information

## Project type
Frontend-only competition prototype.

## Core constraint
HTML5 + CSS3 + Vanilla JavaScript + Chart.js + Web Speech API + localStorage.

## Data model
All application state is browser-local. No backend database is required.

## AI claim boundary
The current coach, scoring and recommendation behavior is deterministic JavaScript demo logic. It must not be presented as medical diagnosis, addiction diagnosis, or a production AI model.
